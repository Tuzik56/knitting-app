Система ведения проектов и учета материалов для вязания: создание цифрового 
каталога пряжи и отслеживание процесса изготовления изделий

## Основные пользовательские сценарии:
1. Просмотр, создание и редактирование карточек пряжи
2. Создание проектов изделий и выбор материалов из каталога
3. Отслеживание статуса и готовности проектов

## Экраны:
1. Каталог пряжи - список карточек пряжи и поиск по нему
2. Карточка пряжи - содержит характеристики мотка и количества в наличии
3. Создание и редактирование карточки пряжи - форма для добавления
   новой или изменения существующей пряжи
4. Список проектов - проекты изделий и их статусов
5. Карточка проекта - описание изделия, материалы, статус, процент готовности 
и заметки
6. Создание и редактирование карточки проекта - форма для описания
   изделия, выбора материалов и изменения статуса

## Запуск frontend
Необходим Node.js 24 LTS
После скачивания репозитория выполнить:

    cd frontend
    npm ci
    npm run dev

Открыть указанный в терминале адрес
