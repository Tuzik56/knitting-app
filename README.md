Система ведения проектов и учета материалов для вязания: создание цифрового 
каталога пряжи и отслеживание процесса изготовления изделий

## Основные пользовательские сценарии
1. Просмотр, создание и редактирование карточек пряжи
2. Создание проектов изделий и выбор материалов из каталога
3. Отслеживание статуса и готовности проектов

## Экраны
1. Каталог пряжи - список карточек пряжи
2. Карточка пряжи - содержит характеристики мотка и количества в наличии
3. Создание и редактирование карточки пряжи - форма для добавления
   новой или изменения существующей пряжи
4. Список проектов - проекты изделий и их статусов
5. Карточка проекта - описание изделия, материалы, статус, процент готовности 
и заметки
6. Создание и редактирование карточки проекта - форма для описания
   изделия, выбора материалов и изменения статуса

## Модель данных
- yarns - пряжа

Поля: id, name, brand, composition, color, weight, length, quantity, notes

- projects - проекты изделий

Поля: id, name, description, status, progress, notes    
Допустимые статусы: «В планах», «В процессе», «Завершен». Прогресс - число от 0 до 100

- project_yarns - связь проектов с пряжей

Поля: project_id, yarn_id.   
Они являются внешними ключами и вместе образуют составной первичный ключ

## Структура frontend
Код в frontend/src организован по структуре:
- app — настройка приложения, маршруты, тема и управление данными
- pages — страницы приложения
- features — формы создания и редактирования
- entities — типы, демонстрационные данные и карточки пряжи и проектов
- shared — общие компоненты интерфейса

Для проверки состояний в app/loadDemoData.ts предусмотрены настройки demoOptions: 
fail: true имитирует ошибку загрузки, empty: true пустые списки.

## Запуск frontend
Необходим Node.js 24 LTS
После скачивания репозитория выполнить:

    cd frontend
    npm ci
    npm run dev

Открыть указанный в терминале адрес

## Подготовка БД
Необходимы Python 3.11 и установленный, запущенный PostgreSQL 17   
Подключиться к PostgreSQL под пользователем с правами создания ролей и баз:

    psql postgres

Создать пользователя, задать пароль и создать базу:

    CREATE ROLE knitting_user WITH LOGIN;
    \password knitting_user
    CREATE DATABASE knitting_db OWNER knitting_user;
    \q

## Запуск backend
После скачивания репозитория выполнить:   

    cd backend    
    python3 -m venv .venv    
    source .venv/bin/activate     
    python -m pip install -r requirements.txt    
    cp .env.example .env

В файле .env указать параметры подключения к PostgreSQL и заданный пароль

## Создание таблиц
Создать таблицы и запустить сервер:

    python -m app.create_tables   
    python -m uvicorn app.main:app --reload

Открыть http://127.0.0.1:8000/docs для просмотра и проверки API
